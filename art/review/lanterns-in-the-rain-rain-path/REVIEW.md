# Rain Path Benchmark Review

## Current state

**Awaiting first generated concept draft.**

Nothing in this directory is approved, production-ready, or eligible for the normal runtime registry. The application must continue to use its structured alpha fallback for `adventure-lanterns-in-the-rain / rain-path` until an explicit manifest promotion occurs.

## Review asset

Expected draft filename:

`rain-path-landscape-concept-v1.png`

The review copy may remain PNG. Any eventual runtime file must be exported as WebP, placed under `art/production/`, remain below 1,100,000 bytes, and pass the production-art validator.

## Required review views

Review the draft at:

- full generated resolution;
- 1600 × 1000 target composition;
- 1024 × 768 crop simulation;
- 800 × 600 compact-tablet simulation;
- grayscale;
- with Fox, Deer, Rabbit, Kitten, and Duckling overlay silhouettes;
- with Fern on the right overlay anchor;
- with stronger-contrast UI framing around the scene.

## Acceptance checklist

### Pixel Pals identity

- [ ] Painterly storybook treatment is materially beyond the alpha SVG renderer.
- [ ] The scene feels warm, safe, observant, and relationship-centered.
- [ ] Willowmere reads as inhabited rather than as a generic fantasy forest.
- [ ] Handmade structures and natural asymmetry are visible.
- [ ] The image does not imitate a named artist, studio, or franchise.

### Story clarity

- [ ] One lantern is visibly tipped.
- [ ] One lantern is visibly partly hidden by leaves.
- [ ] One lantern is visibly upright farther along the path.
- [ ] The three states remain distinguishable without color.
- [ ] The rain changes the familiar path without suggesting danger.
- [ ] The curved path leads attention into the village.

### Live-character composition

- [ ] No character is painted into the environment.
- [ ] The lower-left first-Pal zone remains readable.
- [ ] The lower-right Fern zone remains readable.
- [ ] No critical lantern or path clue is concealed by either overlay.
- [ ] Fox, Deer, Rabbit, Kitten, and Duckling silhouettes all fit.
- [ ] The composition does not imply one canonical starter species.

### Tablet readability

- [ ] Key shapes survive at 800 × 600.
- [ ] Texture does not collapse into noise.
- [ ] Warm lantern accents remain visible but do not bloom excessively.
- [ ] The scene does not require scrolling or panning.
- [ ] A portrait companion composition can preserve the same story.

### Accessibility

- [ ] Meaning is complete in a static frame.
- [ ] No clue relies on color alone.
- [ ] Strong contrast does not erase rain, path, or lantern silhouettes.
- [ ] Decorative details do not compete with the three lantern states.

### Provenance and release integrity

- [ ] Creation method is documented.
- [ ] Source references are recorded.
- [ ] Ownership and service-term review is complete before approval.
- [ ] Human reviewer and approval date are recorded before promotion.
- [ ] Runtime WebP dimensions and compressed byte count are verified.
