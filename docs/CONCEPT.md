# Project Concept

## Why (One Sentence)

Give children a safe, offline-first, tablet-first storybook life simulation where every friendship visibly changes the world — progress comes from relationships, families, and communities, never from combat or manipulation.

## Vibe (Three Keywords)

1. **Wholesome** — kindness has visible consequences; no dark patterns, ever.
2. **Deterministic** — same seed, same inheritance, same world; simulation logic is separated from rendering and fully testable.
3. **Offline-first** — a child opens the tablet and plays; the network is never a requirement for core play.

## Anti-Goals (What This Is NOT)

- **Not a creature-battling game.** Pals are individuals with homes, relationships, and histories — never weapons, units, or collectible statistics.
- **No combat, no competitive play, no PvP.**
- **No monetization dark patterns**: no ads, no behavioral profiling, no loot boxes, no gambling-like mechanics, no manipulative streaks, no purchase prompts directed at children.
- **No public social surface**: no public chat, no DMs with strangers, no location sharing, no child accounts (deferred behind explicit child-safety review).
- **Not a breeding interface.** Family formation includes adoption, mentorship, guardianship, and chosen family; genetics is one system among several and is never destiny.
- **No real-world religious doctrine.** Wonder without doctrine — ambiguity and reverence are preserved without defining gods, worship, or belief requirements.
- **No wholesale legacy migration.** Code from `pixel-pal-paradise-creations` is imported only after passing the six-question migration policy in README.md.
