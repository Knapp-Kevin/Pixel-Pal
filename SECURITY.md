# Security Policy

Pixel Pals is public source in engineering alpha, not a released service. There are no public accounts or cloud saves in the current gameplay architecture.

## Reporting a vulnerability

**Do not post vulnerabilities, tokens, parent PINs, world backups, or children's identifying information in public issues.** Use GitHub's private vulnerability reporting feature if it is enabled for the repository. If it is unavailable, contact the repository owner privately through an established channel before disclosing details. No public email address is designated here.

Please include affected files and revisions, impact, reproducible steps that do not expose personal data, and suggested mitigation when possible. Do not test against other people's devices, files, or private playtests.

## Scope and caveats

The six-digit local parent gate protects against casual child interaction with adult tools; it is **not** authentication against someone with local device access or developer tools. Do not claim it protects a public account or a remote service.

Security reports and remediation are reviewed as development work. No unsupported response-time, bounty, or compliance guarantees are implied.
